# 3.52 英寸 240×360 单色墨水屏移植记录

## 硬件结论

依据 `eink-sch/100ASK_T113-Pro_Base-SCH_V1.3.pdf` 和
`eink-sch/SPI_TO_EPD_V10.pdf`，转接板插在底板 9 针 SPI TFT 接口时：

| EPD 信号 | T113 引脚 | 说明 |
| --- | --- | --- |
| CS | PD10 | SPI1_CS0 |
| SCK | PD11 | SPI1_CLK |
| MOSI | PD12 | SPI1_MOSI |
| RESET | PD13 | 接口原 MISO 脚被转接板改作复位，不能进行 SPI 读操作 |
| DC | PB5 | 命令/数据选择 |
| BUSY | PD22 | 高电平为空闲，低电平为忙 |

这些引脚与 RGB LCD 和 PWM7 有复用冲突，因此 EPD 配置会停用 LCD0 和
PWM7。原需求文档中的 `DC=PD22、BUSY=PB3` 不符合当前两份原理图，不能用于
这块转接板。

## 已接入的软件

- 内核驱动：`drivers/misc/epd_100ask/epd_100ask_240x360.c`
- DTS compatible：`100ask,epd-240x360`
- 用户设备：`/dev/epd_100ask`
- 图像格式：240×360、1 bpp、MSB first；白色位为 1、黑色位为 0
- 每次 `write()` 必须正好写入 `240 * 360 / 8 = 10800` 字节
- 支持 GC、DU、5S LUT 和 30 秒 BUSY 超时

设备树参考片段见 `epd_240x360_t113.dts`。当前板级配置已经直接合并到
`device/config/chips/t113/configs/evb1_auto_nand/linux-5.4/board.dts`。

## 编译

在 SDK 根目录执行：

```sh
./build.sh kernel
./build.sh pack
```

240×360 用户态测试程序：

```sh
make -C eink-3.52/lvgl_epd_demo
```

`eink-3.52/epd_text` 和 `eink-3.52/lvgl_epd_demo/lvgl_epd_demo` 均使用当前
`t113/evb1_auto_nand` 工具链静态链接。

## 上板测试顺序

```sh
dmesg | grep -i epd
ls -l /dev/epd_100ask
./epd_text -c "240x360 EPD OK"
./lvgl_epd_demo
```

正常探测日志应包含：

```text
100ASK EPD 240x360 registered as /dev/epd_100ask
```

若探测等待约 30 秒后失败，先测量 PD22：空闲时应为高电平；再检查 PD13 的
高-低-高复位波形、PB5 的命令/数据电平以及 PD11/PD12 的 SPI 波形。
